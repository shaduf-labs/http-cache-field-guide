Educational calculation: this subtracts the supplied age from each supplied lifetime. It omits clock skew, response age calculations, revalidation, stale extensions, browser history/bfcache, service workers, cache partitioning, provider defaults, and hidden cache-key inputs. It is a teaching aid and policy prompt—not a security boundary, a proof of storage/reuse, or vendor-specific configuration advice.
